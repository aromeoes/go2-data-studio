# Go2 Data Studio

Local operations console. English interface. One persistent application, with independently visible connection, control authority, recording and reconstruction states.

Visual direction: warm graphite workspace, off-white typography, muted jade for healthy/live states, amber for recording and pending actions. A large map canvas is the center of gravity. Monospaced coordinates, paths and counters; humanist system typography elsewhere. No decorative charts or invented measurements.

Layout: narrow spaces rail | map and session timeline | camera and control panel. Persistent top connection strip and bottom recording bar. Session archive and map versions occupy a lower table. Under 1050px the side panel moves below the map. All controls have text names and keyboard focus. Motion requires explicit focus and a held key; blur, disconnect, timeout and mode changes invalidate authority.

Tokens: background #141917, panel #1c231f, raised #252e28, line #354137, text #e7ece5, muted #a0aea2, jade #b5d9ad, amber #f0c478, danger #f38e7d. Radius 12px; spacing 4/8/12/16/24/32. Map grid is functional, not decoration.

Never label replay as a live robot. Unknown quality metrics stay unknown. File sizes use decimal GB. Display camera payload, lidar payload and filesystem total separately.
